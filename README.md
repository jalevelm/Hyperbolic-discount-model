# Hyperbolic-discount- 

**A Python project exploring hyperbolic discounting models.**

**Description:**

This project aims to implement and analyze various hyperbolic discounting models in Python. Hyperbolic discounting is a cognitive bias where individuals tend to prefer smaller, immediate rewards over larger, delayed rewards, even when the larger reward is objectively more valuable. This project will explore different mathematical formulations of hyperbolic discounting and their applications in decision-making, behavioral economics, and other fields.

**Project Goals:**

* Implement different hyperbolic discounting models in Python.
* Develop tools for visualizing and comparing discounting curves.
* Analyze real-world data to investigate the prevalence of hyperbolic discounting.
* Potentially explore applications in reinforcement learning and AI.

**Features (Tentative):**

* **Model Implementations:**
    * Mazur's hyperbolic discounting model
    * Rachlin's discount function
    * Quasi-hyperbolic discounting (beta-delta model)
* **Data Analysis Tools:**
    * Fitting models to experimental data
    * Statistical analysis of discounting parameters
* **Visualization:**
    * Plotting discounting curves
    * Comparing different models graphically
